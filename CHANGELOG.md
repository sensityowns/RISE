# Changelog

## 0.4.0

- Replace the app's lettermark with an orange and black angular peak mark based on the provided logo.
- Add search and category filters to the tweak library; results and counts reflect the implemented tweaks.
- Keep account authentication and Pro/Developer entitlement features explicitly unavailable rather than displaying a fake sign-in flow.

## 0.3.0

- Added a current-user startup manager that can disable and restore registry `Run` entries while preserving their values.
- Display the actual Free edition, assembly version, and implemented tweak count in the app.
- Added MIT licensing, contribution and security policies, issue forms, pull request checklist, and Windows build workflow.
- Document that authentication, Pro/Developer entitlements, and the 130/300-tweak targets are not implemented.

## 0.2.0

- First downloadable Windows x64 preview with system monitoring, ten reversible user-level tweaks, 24 game profiles, process-priority launch profiles, power-plan selection, network diagnostics, and maintenance tools.
- Published as an early preview; see the README for limitations.
